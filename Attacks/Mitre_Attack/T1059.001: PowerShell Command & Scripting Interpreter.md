🛡️ Response & Mitigation
To defend against PowerShell abuse, the following measures are recommended:

Logging: Ensure PowerShell Script Block Logging (Event ID 4104) and Module Logging (Event ID 4103) are enabled.

Constrained Language Mode: Enforce Constrained Language Mode to limit sensitive language elements.

Execution Policy: While not a security boundary, setting Execution Policy to AllSigned or RemoteSigned can prevent accidental script execution.

EDR/SIEM: Monitor for unusual parent-child process relationships (e.g., cmd.exe spawning powershell.exe with encoded commands).
